## Current State

- Datalake tooling is split into two operational apps. basic/datalake_inspector provides lightweight Athena browsing (database/table discovery, starter SQL generation, editable query execution, result preview, CSV download) with awswrangler+boto3 and fixed AWS profile/region defaults. datalake_submissions extends this into a unified workflow by combining Athena querying, schema/column inspection, datetime-aware filtering, column profiling (approx_distinct), and direct submission QA using mapped production/weather/issue/valid datetime fields with overlay charting and forecast diagnostics. These tools are also the primary inspection path for outputs generated by deployed API and scheduled inference modes across environments.
