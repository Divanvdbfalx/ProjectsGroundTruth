# Predefined Prompts

This directory contains reusable, versioned predefined prompts (PPs) for repeated workflows.

## Available PPs
- `journal-entry-write.md`: Draft and finalize a structured journal entry while keeping task tracking aligned.

## Usage
1. Open the relevant prompt file.
2. Follow its `Inputs`, `Instructions`, and `Guardrails` sections.
3. Execute any listed finalize/validation commands.
